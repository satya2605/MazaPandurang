# Maza Pandurang — Backend Boundary

This directory represents the Node.js REST and Realtime API backend service boundary.

## 🏗 Planned Stack
- **Runtime**: Node.js (TypeScript / Express)
- **Database / Auth**: Supabase (PostgreSQL + Realtime subscriptions + Storage)

## 📌 Architecture Role
The backend layer will serve as the middleware between the Flutter client application and backend databases/services.

*Note: The Node.js backend implementation and dependency setup will be established in subsequent development phases.*
